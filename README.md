# AI Code Reviewer Pro 🚀

AI Code Reviewer Pro is an AI-powered application that reviews source code, detects bugs, provides suggestions, generates corrected code, and creates PDF reports.

---

## Features

### 🔐 Authentication
- User Registration
- User Login
- Logout
- User Session Management

### 🤖 AI Code Review
- Upload source code files
- Paste source code
- Automatic language detection
- AI-powered code analysis
- Code quality score
- Bug detection
- Suggestions
- Corrected code generation

### 📄 Reports
- Generate PDF review reports
- Download reports
- Save review history
